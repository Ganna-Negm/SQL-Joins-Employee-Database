# SQL Joins – Employee Database

## 📌 Project Overview

This project focuses on working with a relational employee database using SQL Server.

The database contains information about **Employees, Departments, Projects, and Dependents**, and the project includes practical queries for retrieving and analyzing related data across different tables.

## 🛠️ Skills Applied

* `INNER JOIN`
* `LEFT JOIN`
* `SELF JOIN`
* `GROUP BY`
* Aggregate Functions
* Subqueries
* NULL Handling
* Anti Join concepts
* Filtering with `WHERE`

## 📊 Queries Covered

The project includes queries to:

* Retrieve departments and their managers.
* Display departments and their related projects.
* Retrieve employees and their dependents.
* Find employees working on specific projects.
* Find employees directly supervised by another employee using a Self Join.
* Retrieve employees with no dependents.
* Find departments with no projects.
* Calculate maximum, minimum, and average salaries by department.
* Find employees with the highest salary using a subquery.

## 🎯 Learning Outcome

One of the main goals of this project was to build a better understanding of **SQL JOINs** and how they are used to connect related data across multiple tables.

Rather than memorizing different JOIN statements, the project helped me understand **when and why each JOIN is used**.
